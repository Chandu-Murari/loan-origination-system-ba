# Loan Origination System — Business Analysis Project

## Project Overview

This repository contains end-to-end Business Analysis artifacts for a **Loan Origination System (LOS)** designed for a regional US retail bank (**Horizon Community Bank, Texas**). The project covers the complete BA lifecycle — from stakeholder analysis and elicitation through to BRD, FSD, and process flows.

The goal of the system is to digitise and automate the personal loan application process, reducing manual processing time, improving credit decision accuracy, and delivering a seamless customer experience.

---

## Business Context

**Problem:** Horizon Community Bank processes personal loan applications manually. Applications are received via branch visits or phone calls, assessed by relationship managers using spreadsheets, and approved through email chains. This results in:
- Average processing time of 8–10 working days
- High error rate due to manual data entry
- No real-time visibility for customers on application status
- Compliance risk due to inconsistent documentation

**Objective:** Build a digital Loan Origination System that allows customers to apply online, automates credit assessment via FICO score integration, and routes applications through a structured approval workflow — reducing processing time to under 48 hours.

## Regulatory Context

This project operates within the following US banking regulatory frameworks:
- **ECOA** (Equal Credit Opportunity Act) — no discrimination in credit decisions
- **FCRA** (Fair Credit Reporting Act) — governs use of FICO/credit bureau data
- **GLBA** (Gramm-Leach-Bliley Act) — customer financial data privacy
- **CFPB Guidelines** — consumer financial protection compliance
